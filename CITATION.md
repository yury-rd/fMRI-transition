# Citation

This repository contains code and data for the following paper:

Aleksandr Volkov, Yury Maximov, Tamoghna Chattopadhyay, Paul M. Thompson, and
Ildar Gabitov. *Evaluating State-Transition Models in Short Resting-State fMRI
with Continuous-Dynamics Controls*. Under review at the
[2027 IEEE International Symposium on Biomedical Imaging (ISBI 2027)](https://biomedicalimaging.org/2027/).

For the code and data, also cite *fMRI-transition, version 1.0.0* and link to
[this repository](https://github.com/yury-rd/fMRI-transition).
