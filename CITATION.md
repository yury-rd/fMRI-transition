# Citation

For the original code and data, cite *fMRI Observation Benchmarks, version 1.0.0
(2026)* and its [release](https://github.com/cornada/fmri-observation-benchmarks/releases/tag/v1.0.0).

The associated manuscript is *Evaluating State-Transition Models in Short
Resting-State fMRI with Continuous-Dynamics Controls*. The upstream v1.0.0
release does not list a publication identifier.

This repository is a standalone copy of the transition benchmark, with revised
documentation. The original copyright and license are retained in [LICENSE](LICENSE).
